Job Intelligence — Architecture Overview

End-to-end data flow from user request to gap report

System Architecture & Data Flow
1. FRONTEND
/job-intelligence/page.tsx
FilterBar (role, exp, salary) → "Analyze Market" btn
POST /api/job-intelligence/analyze
↓ receives reportId
Opens SSE → /api/job-intelligence/stream/:id
▼
2. API (Express)
POST /api/job-intelligence/analyze
→ Create JobIntelligenceReport (status: PENDING)
→ Enqueue BullMQ job on "job-intelligence" queue
→ Return 202 { reportId }

GET /api/job-intelligence/stream/:id
→ SSE endpoint, reads progress from Redis pub/sub
▼ BullMQ (Redis)
3. WORKER
Pops job → calls @slh/job-intelligence pipeline

Stage 1: Fetch jobs (all providers in parallel)
Stage 2: Extract skills via LLM (batched)
Stage 3: Aggregate demand analysis
Stage 4: Build user capability profile
Stage 5: Gap analysis (profile vs demand)
Stage 6: Roadmap generation via LLM

→ Publishes progress after each stage
→ Saves final report to DB
